Ten W3Resource NumPy Exercises

This project contains ten beginner-friendly NumPy solutions adapted from the
[W3Resource NumPy exercise collections](https://www.w3resource.com/python-exercises/numpy/index.php).

## Requirements

- Python 3.10 or later
- NumPy

Install NumPy if needed:

```bash
pip install numpy
```

Run all exercises:

```bash
python exercises.py
```

## Exercises

| No. | Exercise | What the program demonstrates |
| --- | --- | --- |
| 1 | NumPy version | Reads the installed NumPy version using `np.__version__`. |
| 2 | List to 1D array | Converts a Python list into a one-dimensional NumPy array. |
| 3 | 3x3 matrix | Uses `np.arange()` and `reshape()` to form a 3×3 matrix. |
| 4 | Null vector | Creates a zero-filled vector and changes its fifth element to `1`. |
| 5 | Evenly spaced values | Uses `np.linspace()` to make eleven values from 0 to 1. |
| 6 | Reverse an array | Reverses an array efficiently with slicing: `array[::-1]`. |
| 7 | Maximum and minimum | Finds the largest and smallest values with `np.max()` and `np.min()`. |
| 8 | Element-wise arithmetic | Adds, subtracts, multiplies, and divides two arrays element by element. |
| 9 | Sort along axes | Sorts a 2D array by columns, rows, and as one flattened array. |
| 10 | Square-root ufunc | Applies `np.sqrt()` to every value in a 2D array. |
